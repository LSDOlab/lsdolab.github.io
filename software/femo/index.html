feMo

Finite-element models for optimization.

Source code ↗Documentation ↗

feMo connects finite-element models to gradient-based multidisciplinary optimization. The associated framework integrates FEniCSx with CSDL, combining derivatives of PDE residuals with sensitivities from other disciplines. Demonstrations include electric-motor shape optimization and aeroelastic analysis, illustrating how field-based physics can participate in a larger system model [1].
