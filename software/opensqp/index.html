OpenSQP

An open implementation of sequential quadratic programming.

Source code ↗Documentation ↗

OpenSQP is an open implementation of sequential quadratic programming within modOpt. It makes the optimizer's numerical components accessible for inspection and modification, supporting research on constrained nonlinear optimization. The lab's Hessian-vector-product study uses this implementation to compare added curvature information with conventional quasi-Newton approximations [1].
