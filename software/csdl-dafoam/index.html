csdl_dafoam

CSDL interface to DAFoam.

Version 0.1.0

Source code ↗Documentation ↗

csdl_dafoam connects CSDL to the adjoint-based CFD solver DAFoam for aerodynamic shape optimization. It wraps the flow solve and its adjoint derivatives as CSDL operations, so geometry from lsdo_geo, mesh deformation from IDWarp-JAX and optimizers from modOpt combine in one differentiable model. The bundled 2D airfoil example reduces drag by 36% over 100 iterations, with adjoint gradients validated against finite differences.
