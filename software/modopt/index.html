modOpt

Optimization library.

Version 0.3.1

Source code ↗Documentation ↗

modOpt is an open-source Python package for developing and comparing optimization algorithms. Modular problem definitions, solvers, and numerical components let researchers modify an algorithm without rebuilding the surrounding workflow. Recording, visualization, and interfaces to modeling frameworks and benchmark problems support testing, while transparent implementations such as OpenSQP make the algorithms accessible for study [1].
