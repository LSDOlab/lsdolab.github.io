lsdo_function_spaces

Function spaces.

Version 1.0

Source code ↗Documentation ↗

lsdo_function_spaces represents continuous fields and geometry with multivariate B-splines, radial basis functions and scattered-data interpolation, and processes multi-patch CAD geometry. Its inverse-projection solvers and analytic derivatives integrate with CSDL for gradient-based design. It is implemented in pure Python with JAX acceleration and underlies the geometry tools in lsdo_geo.
