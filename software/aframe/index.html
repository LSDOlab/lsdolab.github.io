aframe

Beam structural solver.

Version 1.0

Source code ↗Documentation ↗

aframe is a differentiable finite-element solver for three-dimensional beam and frame structures, implemented in CSDL. It uses Euler-Bernoulli beam elements with tube, box, circular and elliptical cross sections, and recovers stress under nodal and inertial loads. Exact derivatives support structural sizing, and the robotic-fish application shows beam states driving a changing body geometry in a coupled simulation.
