Hermit

Reissner-Mindlin shell solver.

Version 0.1.0

Distribution Statement A. Approved for public release: distribution is unlimited. Approved AFRL-2026-1633

Source code ↗Documentation ↗

Hermit is a linear-static Reissner-Mindlin shell solver built on FEniCSx and wrapped as CSDL custom operations. Compliance, mass, center of gravity, stress and nodal fields are differentiable with respect to thickness, composite ply layup, applied loads and mesh coordinates. It supports gradient-based design of composite shell structures.
