Ozone

Differentiable ordinary differential equation solvers.

Source code ↗

Ozone is an open-source Python package for solving ordinary differential equations within gradient-based optimization. Built in CSDL, it computes sensitivities through time integration and supports multiple integration methods and solution approaches. This lets researchers compare time-dependent formulations for optimal control and multidisciplinary design while retaining derivatives of the surrounding model [1].
