PySLSQP

A transparent Python interface to SLSQP.

Source code ↗Documentation ↗

PySLSQP is a Python package that exposes the SLSQP optimization algorithm with utilities for inspecting and continuing optimization runs. Recording, visualization, and restart capabilities help users understand solver progress and revisit saved results. It can be used independently or through the solver interface in modOpt [1].
