csdl_om_connect

CSDL-OpenMDAO interface.

Version 0.1.0

Source code ↗Documentation ↗

csdl_om_connect interfaces models written in CSDL with OpenMDAO, and OpenMDAO models with CSDL. It lets users combine components from the two frameworks in a single multidisciplinary model. The package is released under the LGPLv3 license.
