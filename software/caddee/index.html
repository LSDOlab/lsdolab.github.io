CADDEE

Multidisciplinary aircraft design and analysis.

Source code ↗Documentation ↗

CADDEE is a geometry-centric environment for multidisciplinary aircraft design and analysis. It connects a shared aircraft configuration to disciplinary models and operating conditions, allowing geometry, propulsion, structures, and other subsystems to participate in one optimization. The lift-plus-cruise study demonstrates this system-level modeling workflow across nominal and failure conditions [1].
