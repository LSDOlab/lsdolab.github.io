VortexAD

(Un)steady VLM / panel method.

Version 0.1.0

Source code ↗Documentation ↗

VortexAD is a potential-flow library built in CSDL, offering vortex-lattice and panel methods with fixed, prescribed or free wakes. Its graph representation generates sensitivities for design optimization, while partitioned vectorization manages memory in transient simulations. The fixed-wake solvers are fully operational and the unsteady solvers are still under development, with verification and validation for conceptual aircraft design described in [1].
