CSDL

Modeling framework.

Version 0.1

Source code ↗Documentation ↗

CSDL, the Computational System Design Language, represents numerical models as graphs of mathematical operations. Its compiler generates model evaluations and adjoint-based sensitivities from the same description, reducing the need to implement derivatives separately [1]. The linked CSDL_alpha implementation continues the lab's graph-native modeling research and provides the modeling foundation for several lab packages.
