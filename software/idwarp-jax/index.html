IDWarp-JAX

Volume mesh deformation.

Version 0.1

Source code ↗Documentation ↗

IDWarp-JAX is a JAX implementation of the IDWarp volume mesh deformation package. It propagates surface boundary motion through a volume mesh by inverse-distance-weighted interpolation, with support for local surface rotations and symmetry constraints. Reverse-mode automatic differentiation provides the mesh-coordinate sensitivities needed for aerodynamic shape optimization, complementing the surface deformation in GAMMA.
