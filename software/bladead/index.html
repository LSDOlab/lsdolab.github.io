BladeAD

Differentiable rotor analysis.

Source code ↗Documentation ↗

BladeAD provides differentiable rotor aerodynamic models for gradient-based design. It evaluates the effects of blade geometry and operating conditions, enabling rotor performance to be included in larger vehicle models such as the lift-plus-cruise aircraft. Related rotor-design research develops fast, robust computations based on blade element momentum theory [1].
